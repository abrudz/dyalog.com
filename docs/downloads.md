# Download Dyalog

Dyalog is **free for learning, noodling, and non-commercial use.** A Basic Licence
lets you experiment for personal or non-commercial purposes; commercial use needs a
paid licence — see [Pricing and Licences](pricing.md).

[Go to the Download Zone](https://www.dyalog.com/download-zone.htm?p=download){ .md-button .md-button--primary }

## Platforms

Dyalog APL is available for:

- **Microsoft Windows**
- **macOS**
- **Linux** (DEB- and RPM-based distributions)
- **Raspberry Pi** (via the [Dyalog APT repository](https://packages.dyalog.com/))
- **IBM AIX**
- **Docker** — on [Docker Hub](https://hub.docker.com/r/dyalog/dyalog)

The cross-platform [RIDE](https://github.com/Dyalog/ride/releases) remote IDE is a
separate download.

Installation instructions for every platform are in the
[setup readme](https://docs.dyalog.com/20.0/setup_readme.htm), and the
[Quick Start Guide](quick-start.md) walks through your first session.
