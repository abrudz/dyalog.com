# Products

Dyalog is an application-development platform and interpreter for the Dyalog APL
language. It provides interpreter executables and
[Integrated Development Environments](https://dyalogprod.gos.dyalog.com/products/development-environments/)
on all supported platforms, along with tools and interfaces for data analysis and
software development.

## The APL language

Dyalog APL excels at data processing, algorithm exploration, quick prototyping,
and large-scale application development. Its concise syntax and extensive array
functions have been refined over decades with user input.

[:octicons-arrow-right-24: Learn more about Dyalog APL](https://dyalogprod.gos.dyalog.com/products/apl-language/)

## Connectivity and integration

Deploy Dyalog applications as scripts, desktop GUIs, web applications, or cloud
services:

- Read and write CSV, JSON, and XML data
- SQL database management
- Web services via the Jarvis framework and the HttpCommand HTTP client
- Compiled libraries (`.dll`, `.so`, `.dylib`) and C-library integration
- Microsoft Office interoperability, including Excel
- .NET assembly creation and use
- Live interaction with Python and R

[:octicons-arrow-right-24: Explore tools and interfaces](https://dyalogprod.gos.dyalog.com/products/tools-and-interfaces/)

## Graphics and user interfaces

- **SharpPlot** — a graphics library for publication-quality, customisable charts
- **⎕WC** — a mature Win32 GUI library for Microsoft Windows
- **[DUI](https://github.com/Dyalog/DUI)** — an APL framework for cross-platform desktop apps
- **HTMLRenderer** — build GUIs with React, Svelte, Vue.js, HTML, CSS, and JavaScript
- **Jarvis** — expose APL functions as HTTP endpoints for web front ends
