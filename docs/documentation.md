# Documentation

The complete documentation set for **Dyalog v20.0**, covering the language and its
development environment across platforms.

Prefer the browser? Use the [online documentation](https://help.dyalog.com/20.0/),
or grab the [offline help](https://docs.dyalog.com/20.0/dyalog.chm) and PDF bundles
([colour](https://docs.dyalog.com/20.0/screenpdfs.zip) /
[monochrome](https://docs.dyalog.com/20.0/printpdfs.zip)).

- [Language Reference Guide](https://docs.dyalog.com/20.0/Dyalog%20APL%20Language%20Reference%20Guide.pdf) — primitives, operators, system functions, variables, commands, and error messages
